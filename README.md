# Phân tích dữ liệu thảm họa Titanic

BTL môn Lập trình Python

## Mục tiêu
Phân tích, làm sạch và trực quan hóa dữ liệu thảm họa Titanic.

## Công nghệ
- Python
- Tkinter
- Pandas
- Numpy
- Matplotlib

## Chức năng
- Làm sạch dữ liệu
- Chuẩn hóa dữ liệu
- Vẽ biểu đồ

## Cấu trúc thư mục

```
titanic_disaster_data_analysis/
│
├── main.py               # Chương trình chính (giao diện)
├── data_loader.py        # Đọc dữ liệu CSV
├── data_cleaning.py      # Làm sạch và chuẩn hóa dữ liệu
├── visualization.py      # Vẽ biểu đồ
│
└── data/
    └── titanic_disaster_data.csv   # Dữ liệu Titanic
```
